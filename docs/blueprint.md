# **App Name**: Fran Diarista Landing Page

## Core Features:

- WhatsApp Contact Button: Floating WhatsApp button for immediate customer contact.
- Service Cards: Display cards for 'Residencial Cleaning', 'Commercial Cleaning', and 'Post-Construction Cleanup'.
- Differentiators Section: Showcase differentiators such as 'Punctuality', 'Quality Products', and 'Trust' using modern icons.
- SEO Optimization: Implement Schema.org (JSON-LD) for LocalBusiness in the <head>, and optimize meta tags for Google in Goiânia using keywords: 'Diarista em Goiânia', 'Faxineira Goiânia', 'Serviço de limpeza Goiânia'.
- NAP Footer: Include Name, Address (Goiânia-GO), and Phone number in the footer, along with social media links.

## Style Guidelines:

- Primary color: Professional Navy Blue (#1A365D) to convey trust and professionalism.
- Background color: White (#FFFFFF) to ensure a clean and minimalist look.
- Accent color: Aqua Green (#4FD1C5) to create a sense of cleanliness and freshness.
- Headline font: 'Poppins', sans-serif, for a modern and clean aesthetic. Note: currently only Google Fonts are supported.
- Body font: 'PT Sans', sans-serif, providing a balance of modern appeal and warmth. Note: currently only Google Fonts are supported.
- Modern and minimalist icons to represent services and differentiators, ensuring they align with the overall clean aesthetic.
- A clean, single-page layout optimized for conversions, with clear sections and easy navigation. Fully responsive for mobile devices.
